## What works now

**GUI**

- Open `.gui` and draw it like in-game (DDS sprites)
- Preview layout, or Edit and drag the gold box
- Add toolbox controls, basic text / command / visibility
- Export a `.gui`

**Map**

- **File → Open map** and browse any `.pkg` or `.trv`
- All maps use the same open path; last folder is remembered
- Top-down terrain, props, and track object names
